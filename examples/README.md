## First-suffering recipe

1. Enable chaos (it is ON by default — bold of you to install it).
2. Try to walk to the nearest rack. Note which key walks. Forget it; it
   already changed.
3. Attempt one full cable pull (panel A → panel B) without pressing Escape.
4. Survivors report their shuffle count from the status dot. There is no
   prize. The prize was the keys you pressed along the way.
